# Claude Skill: Caelestia Shell Development

This directory contains a Claude-oriented skill for working in a personal Caelestia shell fork.

Primary file:

```text
SKILL.md
```

Recommended local placement depends on your Claude setup. A practical convention is to keep this directory near your repo notes or copy it into whatever directory your Claude client/agent uses for custom skills.

The skill is written in English and focuses on:

- Caelestia repo navigation
- launcher internals
- QML service/delegate patterns
- C++ config defaults
- build/install workflow
- debugging Quickshell/Caelestia logs
- Git hygiene
- EDP launcher actions as a worked example
